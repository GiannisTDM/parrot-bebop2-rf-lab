# Repository image staging

Fresh screenshots from the updated RF Lab tool should be placed here. Preferred filenames:

```text
rf-lab-modified-5m.png
rf-lab-modified-52m.png
stock-5m.png
historical-2025-epa-discovery.png
```

Keep the uncropped originals until the README composition is complete. Before publication, crop or redact personal paths, unrelated desktop content, MAC addresses, private SSIDs and location information.

Third-party video/forum imagery should normally be linked and described rather than redistributed. Screenshots created by this project and the experimenter's own historical records are preferred.
